# Technical references

For the research behind the workflow, see [References and inspiration](../README.md#references-and-inspiration).

Documentation checked on 2026-11-07. These references support file formats and
setup instructions, not the reliability of this workflow. No provider endorsement
is implied. Account UI and runtime versions still need local verification.

- [Agent Skills specification](https://agentskills.io/specification): Skill metadata and directory format.
- [Pi packages](https://pi.dev/docs/latest/packages): `pi.skills`, local install paths, and installation scope.
- [Pi Skills](https://pi.dev/docs/latest/skills): discovery, resource-relative paths, and `/skill:name`.
- [Grok Bot creation](https://docs.x.ai/grok-bot/bots): role setup through a first message and lasting rules.
- [Grok Skills](https://docs.x.ai/grok-bot/skills-routines-and-automations): private Skills and enabling them per Bot.

The two Grok pages were checked via indexed official documentation; direct page
retrieval was not consistently available. No undocumented ZIP importer, CLI plugin
manifest, or automatic Bot provisioning interface is assumed.

Architecture references are collected in [sources.md](../references/sources.md).
