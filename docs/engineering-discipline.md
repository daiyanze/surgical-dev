# Engineering discipline

Surgical Dev incorporates four engineering habits associated with
[Andrej Karpathy's coding observations](https://x.com/karpathy/status/2015883857489522876)
and the community [Karpathy-inspired guidelines](https://github.com/multica-ai/andrej-karpathy-skills).
This is an independent adaptation, not an official endorsement.

| Habit | Engineer | Verifier |
|---|---|---|
| Think before coding | Surface consequential assumptions and tradeoffs | Identify assumptions undermining approved criteria |
| Simplicity first | Prefer the minimum sufficient design | Report concrete complexity risks separately from preferences |
| Surgical changes | Limit changes to scope and necessary dependencies | Detect unrelated edits or shared-contract drift |
| Goal-driven execution | Use reproducible tests and observable checks | Independently inspect evidence for the current snapshot |

The [engineering-discipline Skill](../skills/engineering-discipline/SKILL.md)
provides the detailed method. The main Surgical Dev Skill includes a short
form, so installing only the entry Skill still applies its core principles.
These are habits within existing roles, not an extra review gate or Bot.
